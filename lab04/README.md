## Пояснения к решению

1. **Разница между `for` и `while`:**
   - `for` используется, когда известно количество итераций (например, перебор `n` чисел или диапазона `range`).
   - `while` используется, когда условие продолжения зависит от данных пользователя или состояния программы (например, ожидание правильного ввода).

2. **Работа `range(start, stop, step)`:**
   - Параметр `stop` никогда не включается в последовательность.
   - Для включения верхней границы при восходящем счете нужно писать `stop + 1`.
   - Для нисходящего счета (`step = -1`) граница остановки должна быть на единицу меньше целевого значения (`end - 1`), чтобы последнее число попало в выборку.

3. **Инициализация максимума:**
   - Нельзя инициализировать максимум нулем или каким-то константным значением, если входные данные могут быть строго отрицательными.
   - Правильный подход: присвоить максимуму первое введенное число. Все остальные сравниваются с ним.

4. **Накопление результата:**
   - Переменные `total_sum`, `count_negative` называются аккумуляторами. Они обновляются на каждой итерации цикла (`+=`).
   - В варианте с пустым вводом (`n=0`) цикл не выполняется, поэтому аккумуляторы остаются в состоянии инициализации (нули), что дает верный ответ «0».
