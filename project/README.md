# Итоговый проект. Список книг для чтения

| Поле | Значение |
| --- | --- |
| Студент | Жуковский Иван Александрович |
| Группа | УБ-64 |
| Язык | Python 3.14.7 |
| Вариант | 2 — Список книг для чтения (amount = страницы, completed = прочитана) |

## Назначение
Консольная программа для учёта книг: добавление, поиск, изменение статуса
«прочитана / не прочитана», удаление, статистика, сохранение в JSON.
Данные хранятся в файле `data.json` рядом со скриптом в UTF-8.

## Запуск

    python main.py              # основной запуск программы
    python test_logic.py        # автоматические тесты логики
    python test_storage.py      # автоматические тесты чтения/записи

## Формат данных
Файл `data.json` содержит список словарей:
```json
{
  "id": 1,
  "title": "Название",
  "category": "Категория",
  "amount": 500,
  "completed": false
}
